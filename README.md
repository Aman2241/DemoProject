# Raj Finance

A comprehensive financial planning web application aimed at helping users manage their personal finances effectively.

## Features

- **Dashboard**: Overview of your financial status with key metrics and charts.
- **Transactions**: View and manage all your income and expenses.
- **Budget**: Set and track budgets for different categories to stay on top of your spending.
- **Investments**: Keep track of your investment portfolio.
- **Goals**: Set financial goals and monitor your progress towards achieving them.
- **Settings**: Customize your experience with light/dark mode and other preferences.

## Tech Stack

- **Frontend**: React
- **Build Tool**: Vite
- **Styling**: Tailwind CSS, clsx, tailwind-merge
- **Icons**: Lucide React
- **Charts**: Recharts
- **Animations**: Framer Motion
- **Testing**: Vitest, React Testing Library

## Getting Started

1.  **Clone the repository:**
    ```bash
    git clone <repository-url>
    cd RajFinance
    ```

2.  **Install dependencies:**
    ```bash
    npm install
    ```

3.  **Run the development server:**
    ```bash
    npm run dev
    ```

4.  **Build for production:**
    ```bash
    npm run build
    ```
